# AceMux 2.0.1

Bug-fix release for the stream form: auto-detection now respects what you type, so reading the channel name and provider from the broadcast never overwrites your own edits.

## Fixes

- **User input wins** — detection only replaces fields that are empty, still hold the infohash default or were written by a previous detection; anything you typed is left untouched.
- **Stale detection values are cleared** — if detection fails, or a previously detected stream can no longer be read, the values it filled are removed so the form never submits mixed metadata.
- **Re-detection on ID change** — changing the AceStream ID runs detection again while the relevant fields are still empty or auto-filled.
- **Cancel resets the form** — cancelling the create form (or finishing a successful add) clears fields, errors and detection status.

## Upgrade notes

- Pull the new tag (`ghcr.io/la-lo-go/acemux:2.0.1` or `lalogo/acemux:2.0.1`) or `latest` and run `docker compose up -d`.
- No database migrations in this release.
