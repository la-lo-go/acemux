# AceMux 1.0.0

First stable release. AceMux manages your AceStream links and publishes them to Plex, Jellyfin, Threadfin and VLC as live TV, sharing a single stream session per channel.

## Highlights

- **Plex & Jellyfin integration** — `GET /playlist.m3u` (M3U with `tvg-id`, `tvg-name`, `tvg-logo`, `group-title`, `tvg-chno`) and `GET /xmltv.xml` (XMLTV guide). Jellyfin reads them directly; Plex goes through the bundled Threadfin service.
- **Shared stream sessions** — the AceStream engine only serves one player per stream, so AceMux keeps a single download per channel and fans it out to every viewer (Plex, Jellyfin, VLC and the web player). Ref-counted, with per-stream and global limits and slow-client eviction.
- **Built-in player** — the web player now plays the shared MPEG-TS session (`mpegts.js`), so the browser joins the same session as the rest of your clients.
- **TV metadata & EPG** — per-stream `tvg-id`, `tvg-name`, group and channel number, with automatic name lookup from the engine. `tvg-id`/`tvg-name` feed both the M3U and the XMLTV.
- **Threadfin auto-refresh** — adding, editing or removing a stream refreshes Threadfin automatically.
- **Favorites, search and sort** — star channels, filter by name and sort the library.
- **Cards and table views** — switch between a gallery grid and a compact table.
- **Import / Export** — back up and restore your library as JSON (with a schema you can hand to an LLM to format a list).
- **PWA** — installable, with manifest and service worker.
- **Docker-first and cross-platform** — runs the same on Linux, NAS, Windows and macOS; data lives in a named volume (bind mounts supported).

## Endpoints

| Endpoint | Description |
|---|---|
| `GET /playlist.m3u` | M3U playlist (`?token=<API_TOKEN>`) |
| `GET /stream/:id` | Shared MPEG-TS stream (`?token=`) |
| `GET /xmltv.xml` | XMLTV guide (`?token=`) |
| `GET /healthz` | Status JSON |

## Upgrade notes

- New environment variables: `PUBLIC_URL`, `API_TOKEN`, `EPG_DAYS`, `THREADFIN_URL`, `MAX_CLIENTS_PER_STREAM`, `MAX_CONCURRENT_STREAMS`, `STREAM_STOP_GRACE_MS` and `ACESTREAM_PID` (see `.env.example`).
- The database schema is migrated automatically (adds the TV metadata columns and the favorite flag).
- Docker images: `ghcr.io/la-lo-go/acemux:1.0.0` and `lalogo/acemux:1.0.0`.
