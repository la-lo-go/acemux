# AceMux 2.0.0

AceMux is now a self-hosted live TV gateway for AceStream: it publishes your channels straight to Plex with its own virtual HDHomeRun tuner, reads the real channel name from the broadcast itself and lets you swap a dead AceStream source without touching anything else.

## Highlights

- **Built-in HDHomeRun tuner for Plex** — no extra service required. AceMux serves `/discover.json`, `/lineup_status.json`, `/lineup.json`, `/device.xml`, `/capability` and a numeric-id XMLTV guide at `/hdhr/xmltv.xml`, so Plex Live TV & DVR reads the lineup and the guide directly from AceMux. Jellyfin, Emby, VLC and Kodi keep using `/playlist.m3u` + `/xmltv.xml`.
- **Channel metadata from the broadcast (DVB SDT)** — AceMux parses the MPEG-TS Service Description Table and reads the real channel name and provider (for example `DAZN F1 Spain` / `Movistar PR`) straight from the stream. Adding a stream auto-fills name, TVG Name and a suggested TVG ID; `/api/probe` and `/api/test/:id` expose the detected values and the channel tooltip shows them.
- **Swap a stream's AceStream ID in place** — edit the ID of an existing channel to point it at a new infohash; every other field (name, logo, TVG IDs, group, channel number, favorite and creation date) is preserved, so TV clients keep their mapping. Invalid ids are rejected and duplicates return `409`.
- **Stable channel numbering** — numbers are auto-assigned, validated, deduplicated and never recycled (persisted high-water mark), and existing libraries are backfilled once. The HDHomeRun `DeviceID` is checksum-valid and persisted per installation, overridable with `HDHR_DEVICE_ID`.
- **Cheap `HEAD /stream/:id`** — clients can probe a channel without opening a P2P session, and `/api/test/:id` returns peers, speed and SDT metadata.
- **Simpler stack** — Threadfin is gone: two containers (AceMux + AceStream engine) and SQLite.

## Breaking changes

- **Environment variables renamed** for clarity: `ACESTREAM_ENGINE_URL`, `PUBLIC_BASE_URL`, `ACEMUX_API_TOKEN`, `DATABASE_PATH`, `EPG_FILLER_DAYS` and `ACESTREAM_PLAYER_ID`. Update your `.env`/compose before upgrading. New optional `HDHR_DEVICE_ID`.
- **Threadfin removed** from the stack, code and docs. Existing installs can delete the service and its volumes.
- **Default timezone is now `UTC`** (was `Europe/Madrid`). Set `TZ` explicitly to keep local times.

## Endpoints

| Endpoint | Description |
|---|---|
| `GET /playlist.m3u` | M3U playlist for Jellyfin, Emby, VLC and Kodi (`?token=`) |
| `GET /xmltv.xml` | XMLTV guide (`?token=`) |
| `GET /stream/:id` | Shared MPEG-TS stream (`?token=`, `HEAD` supported) |
| `GET /discover.json` | Virtual HDHomeRun tuner descriptor (Plex) |
| `GET /lineup.json` | Virtual HDHomeRun channel lineup (Plex) |
| `GET /lineup_status.json` | HDHomeRun scan status |
| `GET /device.xml`, `GET /capability` | HDHomeRun device description |
| `GET /hdhr/xmltv.xml` | Plex guide (numeric channel ids matching the lineup) |
| `GET /api/probe?id=` | SDT service name/provider + engine metadata for an infohash |
| `GET /api/test/:id` | Real stream test: peers, speed and SDT info |
| `GET /healthz` | Status JSON |

## Upgrade notes

- Database migrations run automatically: channel numbers are backfilled and validated, and the installation's HDHomeRun device id is created on first run.
- Plex: remove the old tuner/DVR and add AceMux by network address (`<IP>:4321`), then choose **"Have an XMLTV program guide on your server?"** → `http://<IP>:4321/hdhr/xmltv.xml`. Use **Rescan channels** after adding or swapping streams.
- The tuner endpoints cannot send `ACEMUX_API_TOKEN` (Plex does not send credentials), so keep AceMux on a trusted LAN or behind a reverse proxy.
- Docker images: `ghcr.io/la-lo-go/acemux:2.0.0` and `lalogo/acemux:2.0.0`.
